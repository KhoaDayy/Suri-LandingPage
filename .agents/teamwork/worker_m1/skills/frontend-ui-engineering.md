# Frontend UI Engineering (Worker M1 Local Reference)

Core Principles:
- Accessible (WCAG 2.1 AA), keyboard navigable, proper aria-labels
- Design system adherence: Tailwind tokens, responsive mobile-first (320px to 1440px+)
- Avoid AI aesthetics (no generic purple everything, no excessive inconsistent roundings, purpose-driven layouts)
- Semantic typography, proper contrast, elegant liquid-glass borders and backdrop blurs
