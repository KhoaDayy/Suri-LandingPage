# Skill: test-driven-development (Local copy)
Drives development with tests; opaque-box behavioral assertions; requirements-driven derivation.
Key principles:
1. Test behavior and outcomes, not interactions or implementation details.
2. DAMP over DRY in tests (descriptive, readable, self-contained).
3. 4-tier test architecture: feature coverage, boundary/corner cases, cross-feature combinations, real-world/build verification.
4. Deterministic assertions, no facade tests, strict exit codes.
